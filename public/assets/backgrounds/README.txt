# Directorio de Fondos de Pantalla (Backgrounds)
Coloca aquí las imágenes de fondo para las diferentes escenas y mazmorras (JPG, PNG o WebP).

Ejemplos de nombres sugeridos:
- seoul_night.jpg (Fondo de la ciudad / menú)
- hunter_agency.jpg (Asociación de cazadores)
- dungeon_gate.jpg (Entrada al calabozo / portales)
- dungeon_cave.jpg (Combate en caverna)
- shadow_monarch.jpg (Reino de las sombras / resurrección)
- hunter_shop.jpg (Tienda de artefactos)

En la aplicación se acceden mediante la ruta:
`/assets/backgrounds/nombre_del_archivo.jpg`
O puedes subirlos directamente desde la interfaz usando el botón "Fondo de Pantalla".
